01 · 下载与启动

下载 MediaHarvest Windows x64

  1. 登录你的 GitHub 账号，下载并解压 ZIP，运行 MediaHarvest.exe。包内附有 README 使用说明。
  2. 第一次打开，进入「设置 → 运行依赖」，检测并安装缺失的 yt-dlp 和 FFmpeg。
  3. 粘贴视频链接，点击「解析」，选择清晰度；然后分别保存，或点击「全部下载」。
  4. 完整台词首次使用会下载 whisper.cpp 程序和约 142 MiB 的多语言 base 模型；安装完成后在本机识别。

这是 Windows 便携程序包，桌面壳使用 Wails/WebView2。GitHub 构建产物保留至 2026-11-10；源码和构建流程保留在个人仓库中。它不是公开 Release。

04 · 已修复的问题

  • 修复直链“音频”只是把视频字节改成音频扩展名的问题。
  • 修复批量任务中切换链接可能混入其他视频素材，以及切换设置页后丢失台词和进度的问题。
  • 加入失败项重试、取消首次安装、同名导出不覆盖和音频素材复用。
  • 修复验收脚本只看最后一条命令退出码的问题；每步失败都会停止验收。
  • 补齐 Node 类型和 Svelte 测试编译，修复 Windows 路径断言和开发版更新判定。
  • 使用独立应用数据目录并阻止官方更新覆盖增强版；保留 MIT 许可和原项目署名。
  • 同步来源审计记录，更新 yt-dlp 固定版本及官方发布摘要。

05 · 尚未验证与使用边界

公开平台在线链接与桌面交互仍需实测。本轮没有逐条测试抖音、快手、小红书、B 站等在线链接，也没有在你的电脑上完成点击操作验收。公开语音样本通过，不能等同于每个平台都能成功解析。
  • 平台登录限制、限流、Cookie 和提取器适配会影响解析成功率；手动 Cookie 文件可用于相应下载链路。
  • 完整台词属于语音识别，可能错字、漏字；不保证逐字准确，也不把发布正文冒充台词。
  • 没有原声、没有可用封面或平台未返回正文时，相关素材可能不可用。
  • 识别程序首次安装需要联网；本次交付与真实识别验收针对 Windows x64。
