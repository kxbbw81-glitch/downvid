# 链接解析后的素材与完整台词工作流

状态：实现基线，尚未交付功能。适用基线：本 Fork 的 `main`，2026-10-22 的 `af5a3ef`。本文件记录本分支的产品边界和验收口径，避免将发布正文与视频口播混同。

## 用户流程

粘贴一个可访问的视频链接并点击解析。解析结果先展示标题、作者、平台、视频格式、完整的发布正文和封面；音频可选择保存为单独文件。视频口播进入转写任务，结束后在独立区域展示逐字结果及时间戳。用户可以分别保存视频、原声、封面、台词，或点击「全部下载」将可用项目写入同一个文件夹。任何一项失败仅影响本项，可单独重试。

「完整台词」是识别视频中实际说出的词句；平台的 `description` 是作者发布的正文，二者必须分别标注。无口播、语言不支持、识别失败时明确展示状态，不能用标题或发布正文代替台词。音频指原视频的完整声音，包括人声、音乐、背景音，不执行声源分离。

## 当前代码基础与实现位置

- 主线是 `app/` 下的 Go + Wails + Svelte 5。解析结果在 `app/frontend/src/components/ParseResult.svelte`；状态机在 `app/frontend/src/lib/store.svelte.ts`；前后端边界统一在 `app/frontend/src/lib/backend.ts`。旧 Electron 版先维持可用性，不能把旧版 `src/` 的修改误当主线交付。
- 解析结果已含 `description`、`thumbnail`、`audioFormats`、`subtitles`，但展示层 `VideoInfo` 尚未保留发布正文；应在 `types.ts` 与 `backend.ts` 原样传递。
- 现有单一 `mode` 仅支持视频、音频、字幕三选一；「全部下载」需要独立的组合操作及四项结果状态。不能通过连续切换全局 `mode` 来创建任务，因为异步队列会读到变化后的选择。
- 抖音/快手具有 CDN 直链路径：`app/bindings_download.go` 的 `startDirectDownload` 现在直接把返回字节写到输出路径，音频模式却将扩展名设为 `.m4a`。必须下载原始媒体后调用 FFmpeg 提取音频，并使用可取消的任务上下文、临时文件与原子完成操作；失败不得留下伪装成音频的文件。
- 封面保存应通过 Go 后端读取图片（带原页面 Referer，遵循当前代理设置）并写入输出目录；前端已有 `FetchImage` 供预览，不应将 data URL 直接当远程链接保存。
- 完整台词优先使用可访问、语言匹配且内容有效的字幕。没有有效字幕时，提取音频后调用本地可安装的语音识别引擎。首版选用本地方案，避免让一个桌面下载器默认上传用户视频音频。模型下载、磁盘占用、运行能力、识别中取消和错误提示必须有明确实现。实际速度与正确率由验收视频测量，不预设百分比承诺。

## 任务与文件约束

按解析结果 ID、链接及选择快照创建任务；同一条解析结果的组合任务共用素材缓存，避免为视频与转写重复拉取原视频。下载目录下用安全化标题和稳定 ID 建子目录；防止目录穿越、文件重名覆盖和过期直链。输出项为视频文件、原声文件、原封面图片、台词 TXT 和可选 SRT；发布正文单独复制及 TXT 导出。每项分别记录待处理、处理中、已完成、不可用或失败，全部下载只汇总现有可用项并给出部分成功结果。

字幕优先策略必须标明来源：平台字幕或语音识别；对自动字幕同样允许用户校对。TXT 保留段落，SRT 保留时间戳。下载任务取消时终止 FFmpeg / 识别子进程、清理临时文件，并保持已经成功的其他项目。用户重新解析之前禁止复用过期的 CDN 直链。

## 实施顺序

1. **素材落地**：补齐发布正文展示/复制/导出、封面保存及直链音频真实提取；验证独立按钮与文件内容。
2. **台词转写**：字幕优先，再接本地语音识别；增加独立进度、取消、TXT/SRT 和复制按钮。
3. **全部下载**：并发受控的组合任务、素材复用、每项状态、部分失败重试和安全文件名。
4. **安装与发布**：验证 Windows 构建及实际短视频；修改本 Fork 的仓库坐标、更新地址和品牌标识，保留 MIT 版权与许可文本；没有安装包验收前不标记完成。

## 验收样例

- 抖音与快手各一条：音频文件能播放且时长与原视频相符，声轨含人声及背景音，文件类型与扩展名一致。
- 有字幕一条、无字幕有口播一条、无口播一条：分别验证字幕来源、识别、空内容状态；台词与发布正文独立。
- 封面带防盗链一条：独立保存的图片可离线打开，失败提示清楚。
- 「全部下载」一条：视频/音频/封面/台词位于同一子目录，素材不会重复下载；故意让一项失败，其余项仍可使用且失败项可重试。
- Windows 真机验证：解析后不自动下载；各项可以单独保存；复制保留换行；取消任务无伪完成文件；构建产物来自本 Fork 而不是原仓库。
